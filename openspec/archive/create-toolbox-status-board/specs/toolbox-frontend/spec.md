## ADDED Requirements

### Requirement: Tool Status Visualization
The system SHALL provide a dedicated view to track the development status of Toolbox tools.

#### Scenario: View tool statuses
- **WHEN** the user navigates to the Status Board
- **THEN** the system displays tools categorized by their status (e.g., Live, In Construction, Queue)
- **AND** each tool card shows relevant details (name, brief status description)

#### Scenario: Status categories
- **WHEN** viewing the board
- **THEN** distinct visual indicators (columns or sections) separate "Live", "In Progress", and "Planned" tools
