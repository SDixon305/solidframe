# Change: Create Toolbox Status Board

## Why
Users need visibility into the development status of various tools within the Toolbox (e.g., which are ready, in progress, or in the backlog) to better plan their work and understand platform capabilities.

## What Changes
- Add a new "Status Board" page to the Toolbox frontend (`site/toolbox`).
- Implement a Kanban-style or list view showing tools categorized by status (e.g., Live, In Progress, Backlog).
- Use mock data initially for the frontend implementation.

## Impact
- **Affected Specs**: `toolbox-frontend`
- **Affected Code**: `site/toolbox/src/app`, `site/toolbox/src/components`
