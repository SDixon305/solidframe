## ADDED Requirements
### Requirement: High-End "Command Center" Aesthetic
The Toolbox UI SHALL use a premium, "tech-noir" design language to convey competence and sophistication.

#### Scenario: Visual Depth
- **WHEN** user views the dashboard
- **THEN** elements SHALL use glassmorphism (frosted blurs) and subtle border gradients to create depth
- **AND** the background SHALL have subtle, continuous motion ("alive" feel)

#### Scenario: Reactive Elements
- **WHEN** user hovers over a tool card
- **THEN** the card SHALL "glow" or highlight responsively (e.g., following cursor or intensifying border)

### Requirement: Technical Typography
The UI SHALL use a mixed typography system to reinforce the engineering/technical nature of the tools.

#### Scenario: Data Display
- **WHEN** displaying IDs, status codes, or technical metrics
- **THEN** the system SHALL use a monospaced font

#### Scenario: General Text
- **WHEN** displaying names and descriptions
- **THEN** the system SHALL use a clean, modern sans-serif font
